# Инсталација пакета

::: danger
Имајте на уму да кораци за подешавање AI агената не обухватају теме безбедности, мреже и конфигурације (нпр. SSL
сертификате, конфигурацију хост имена, подешавања Elasticsearch). Уместо тога, ови кораци се односе на основно подешавање Zammad-а. Да бисте га користили у продукцији, уверите се да га правилно конфигуришете према осталим ресурсима у овој
документацији.
:::

Ако желите да инсталирате Zammad путем LLM оператера, урадите тако што ћете
усмерити ваш оператер на један од фајлова са упутствима за инсталацију који
се налазе испод.

## Покретање преко Docker Compose

Изворни код Zammad-а можете пронаћи на GitHub-у у [Zammad
репозиторију](https://github.com/zammad/zammad-docker-compose){target=_blank}.

Предуслови

- Радно Docker Compose окружење
- Инсталација

Увод

```plain
https://github.com/zammad/zammad-org/issues
```

## Инсталација путем Управљача пакета

Овај фајл покрива инсталацију путем управљача пакета, укључујући
Elasticsearch.

Предуслови

- Оперативни систем хоста: Ubuntu (22.04 или 24.04) или Debian (12 или 13).
- Инсталирани `curl`, `apt-transport-https` и `gnupg`.
- Локализација са подршком за UTF-8.

Увод

```plain
https://github.com/zammad/zammad-org/issues
```
