# Zammad holen

Sie benutzen Zammad noch nicht? Sie werden es mögen! Wählen Sie unten Ihre
bevorzugte Option oder lesen Sie in den folgenden Abschnitten weiter.

Wenn Sie Fragen haben, können Sie sich gerne [an
uns](https://zammad.com/de/company/contact){target=_blank} wenden und einen
Blick in das [Community Forum](https://community.zammad.org/){target=_blank}
werfen, wo Sie nützliche Informationen und Hilfe finden können.

<VPDocFeatures />

## Zammad testen

Wir sind sicher, dass Ihnen Zammad gefällt! Der einfachste Weg, es zu
testen, ist die Verwendung einer [kostenlosen
Testversion](https://zammad.com/de/getting-started){target=_blank}. Sie
können damit herumspielen und dann zu einer offiziellen Instanz wechseln,
wobei Sie entweder Ihre Daten behalten oder mit einem leeren System neu
beginnen können.

## Nutzen Sie Zammads Hosting-Service

Wenn Sie Zammad produktiv einsetzen möchten, besuchen Sie unsere andere
Seite [zammad.com](https://zammad.com/de/pricing){target=_blank}, wo Sie die
Preise für Hosting Services von Zammad finden können.

## Selbst gehostete Installation

Sie können Zammad auch selbst hosten. Lesen Sie unsere
[Installationsanleitung](/de/get-started/installation/prerequisites) und
sehen Sie, welche Variante Ihren Bedürfnissen entspricht.

Wenn Sie Zammad selbst hosten und Support wünschen, nimmt unser
Vertriebsteam gerne Kontakt mit Ihnen auf. Hinterlassen Sie einfach eine
[Nachricht](https://zammad.com/de/company/contact){target=_blank}.
